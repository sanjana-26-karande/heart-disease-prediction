# Heart Disease Prediction

An end-to-end machine learning project that predicts the likelihood of heart disease from clinical features, compares four models, explains predictions, and serves them through a web app.

> **Disclaimer:** educational project only. Not a medical device and not medical advice.

## Highlights
- Models compared: Logistic Regression, Random Forest, SVM, XGBoost (5-fold CV + GridSearch, **tuned for recall**)
- Metrics: accuracy, precision, recall, F1, ROC-AUC, confusion matrix
- Explainability: SHAP (notebook) and permutation importance (script)
- Streamlit web app for interactive risk prediction

## Dataset
UCI Heart Disease (Cleveland), 303 rows, 13 features, binary target (1 = disease present). Included at `data/heart.csv`.

## Project structure
```
data/heart.csv
notebooks/heart_disease_prediction.ipynb   # EDA, training, SHAP (runs in Google Colab)
src/train.py                               # reproducible training script
app/app.py                                 # Streamlit app
models/                                    # saved model, metrics, plots
requirements.txt
```

## Run locally (VS Code)
```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (Mac/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python src/train.py             # trains models, saves best model + plots
streamlit run app/app.py        # launches the web app
```

## Run in Google Colab
Upload `notebooks/heart_disease_prediction.ipynb` to Colab and run all cells. The dataset downloads automatically.

## Results
See `models/metrics.csv`, `models/roc_curves.png`, `models/confusion_matrix.png`, `models/feature_importance.png` (generated by `src/train.py`).

## Limitations and future work
Small single-source dataset, no external validation, no probability calibration. Next steps: merge multiple heart datasets, calibrate probabilities, add a model card, and deploy on Streamlit Community Cloud.
